# Product Map: Classic Templates + Agent Templates

## Strategy

Build two products from one archetype:

```text
Classic Notion template = databases, dashboards, checklists
Agent template = instructions, triggers, access, prompts, operating rules
```

Do not copy existing templates. Use public categories and visible demand as inspiration, then create original localized versions.

## Priority source categories

Use crowded categories only as signal, not as direct target.

- Project Management
- Personal Planner
- Habit Tracking
- CRM
- Budgets
- Food & Nutrition
- AI Prompts
- Learning
- Content Planning
- Task Triage
- Inbox / Morning Brief

## Product pair format

Each product should have:

1. Classic template
2. Agent instructions
3. Lite version
4. Pro version
5. Marketplace listing
6. Keywords
7. Screenshots
8. Optional Google Sheets/PDF companion

## Selection rules

Build only if the product has at least 4 of these:

- repeated activity
- database/list habit
- calendar/deadlines
- clear pain
- language localization value
- agent can add obvious value
- marketplace keyword can be specific
- Pro version can be meaningfully better than Lite

## Lite vs Pro

Lite:

- 1–2 databases
- short guide
- basic dashboard
- free

Pro:

- 4–6 databases
- sample data
- dashboards
- checklist pack
- agent instructions
- marketplace listing
- paid
