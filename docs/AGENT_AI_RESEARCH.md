# Agent.ai Research Notes

## Current read

Agent.ai is a real marketplace/professional network for AI agents.

It has:

- Agent Network
- Builder Network
- Agent profiles
- Builder profiles
- Public run counts
- Pro agents
- Premium agents
- Free marketplace agents

## Monetization observed publicly

Agent.ai pricing page shows:

- Pro plan: $25/month
- Individual Premium agents: $10/month per agent
- Pro gives access to all Agent.ai Pro agents
- Premium agents can be subscribed to individually
- Marketplace agents are still free to use

Important uncertainty:

Public pages do not clearly state whether independent builders can directly set prices or receive revenue share from Premium/Pro subscriptions.

Therefore, treat Agent.ai first as:

```text
agent discovery + validation + lead generation channel
```

not as guaranteed direct revenue channel.

## Best use for us

Use Agent.ai to test agent demand fast.

For each agent:

```text
Agent.ai free/public agent
→ collect runs and feedback
→ link to paid Notion/Gumroad bundle
→ custom service upsell
```

## What appears to work

Top visible categories:

- company research
- prospect research
- outreach drafting
- meeting prep
- web copy analysis
- cold email analysis
- competitive brief
- industry/trend research
- YouTube/content tools
- prompt improvement

## Build rule

Do not build generic agents.

Build localized or verticalized versions:

```text
Czech Website Copy Analyzer
Czech Outreach Drafter
AI Workflow Finder for Small Businesses
Czech Meeting Prep Brief
Small Business SOP Builder
```

## First experiment

Build 3 agents:

1. AI Workflow Finder for Small Businesses
2. Czech Website Copy Analyzer
3. Czech Outreach Drafter

Measure:

- runs
