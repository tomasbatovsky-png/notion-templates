# Pipeline

## 1. Idea input

Use a narrow niche and one repeated problem.

Good:

```text
Včelársky denník pre hobby včelára s 5–30 úľmi.
```

Bad:

```text
Ultimate productivity dashboard.
```

## 2. YAML config

Every product starts as a YAML file.

Required:

- template_name
- language
- target_user
- main_problem
- databases
- sections

## 3. Generation

The generator creates a Notion draft. Treat it as 70% finished.

## 4. Manual polish

Manual polish is where quality is created:

- better dashboard layout
- screenshots
- cover
- sample data
- short guide
- final wording

## 5. Marketplace listing

Generate the draft listing, then rewrite the first 2–3 lines manually.
